# Artwork

Midjourney watercolor stills, cropped and wired into the app's asset catalog
(`LifeInNumbers/LifeInNumbers/Assets.xcassets`):

| File | Subject | Where it appears |
|------|---------|------------------|
| `grid.png` | dog lying on the colored-square grid | Life in Months tab |
| `heart.png` | big heart with the crowd | Numbers dashboard |
| `milestones.png` | cake on the hillside path with flags | Milestones tab |
| `rooftop.png` | dog watching the moons | Reflection tab |
| `icon.png` | hourglass with the heart inside | app icon (both platforms) |

The memory icons live in [`icons/`](icons/README.md). To replace a piece of
art: drop the new still here under the same name, re-crop, update the matching
imageset, and commit.
