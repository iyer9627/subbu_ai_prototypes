# Product Ideas

A structured catalog of product ideas — things that are feasible to build with today's technology and could genuinely help people.

## How This Works

- **Capture** unstructured thoughts into individual idea files using the [template](_template.md)
- **Categorize** each idea by domain and maturity
- **Evolve** ideas from raw thought to validated concept to prototype-ready spec

## Idea Maturity Levels

| Level | Label | Description |
|-------|-------|-------------|
| 1 | `raw` | Unstructured thought, just captured |
| 2 | `shaped` | Problem and solution articulated clearly |
| 3 | `validated` | Researched feasibility, identified users and competition |
| 4 | `spec-ready` | Clear enough to start prototyping |

## Rating Dimensions

Each idea is scored across six dimensions (1-10 scale):

| Dimension | What it measures |
|-----------|-----------------|
| Problem clarity | How clearly defined and universally felt is the pain? |
| Market size | How large is the potential user base? |
| Uniqueness | How differentiated is this from what exists? |
| Feasibility | How buildable is this with today's technology? |
| Monetization | How clear and viable are the revenue paths? |
| Emotional pull | How strongly does this resonate on a human level? |

**Overall score** = weighted average favoring problem clarity, uniqueness, and feasibility.

## Adding a New Idea

1. Copy `_template.md` into `ideas/` with the naming convention `YYYY-MM-DD-short-slug.md`
2. Fill in as much or as little as you have — raw thoughts are welcome
3. Update the index table above
4. Set the maturity level honestly — it's fine to start at `raw`
